# Support

Thanks for using Nitpick! If you need help or run into issues, here's how to get support.

## Reporting Bugs

If you've found a bug, please [open a GitHub issue](https://github.com/AdrianPrice/Nitpick/issues/new?labels=bug&template=bug_report.md) with:

- A description of what happened
- Steps to reproduce the issue
- What you expected to happen
- Your macOS version
- Screenshots if applicable

## Feature Requests

Have an idea for Nitpick? [Open a feature request](https://github.com/AdrianPrice/Nitpick/issues/new?labels=enhancement) describing what you'd like and why it would be useful.

## General Questions

For general questions or discussion, [open an issue](https://github.com/AdrianPrice/Nitpick/issues/new) and tag it with "question".

## Contact

For anything else, reach out via [GitHub Issues](https://github.com/AdrianPrice/Nitpick/issues).
